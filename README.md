# PySide6 Live Chart Dashboard

## Overview
PySide6 Live Chart Dashboard is a real-time chart visualization tool built with **PySide6**, **Chart.js**, and **Sun Editor**. It enables dynamic chart updates and live data visualization in a PyQt-based GUI.

## Features
- **Real-time Chart Updates**: Uses Chart.js for smooth live visualizations.
- **Rich Text Editing**: Integrated **Sun Editor** for content management.
- **PySide6 GUI**: A robust and scalable Qt-based interface.
- **Poetry for Dependency Management**: Ensures a clean and manageable Python environment.
- **Docker Support**: Easily deployable with a Docker image.

## Installation
### Prerequisites
- Python 3.11+
- Poetry (for dependency management)

### Install Dependencies
```sh
poetry install
```
